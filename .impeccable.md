## Design Context

### Users
Dan: a full-time video editor using Cool Story (formerly Studio Screen) as a personal tool on a 4K display at 150% Windows scaling. He records screen tutorials and demos and wants to be almost done with the edit the moment recording stops. Time and attention are budgeted; he tests by hand.

### Brand Personality
Calm, capable, a little techy, with a dry sense of humour (the name). The tool should feel like a good assistant editor: it does the rough cut, then gets out of the way. Emotional goal: confidence ("that already looks finished").

### Aesthetic Direction
Dark editing-suite UI (long sessions next to footage), cool slate neutral surfaces, signal-violet accent (`--accent: #8f80ff`; chosen 2026-09-22 over cyan, blue and lime because it differs from every timeline clip colour), DM Sans (existing brand face; readability pass kept it). References: Screen Studio's restraint, FocuSee's feature reach. Anti-references: tiny grey-on-grey labels, dense control walls, neon-on-dark "pro" styling (techy means a crisp accent, never glows).
Colours that carry meaning stay fixed whatever the accent: red = removed footage / recording / discard, green = export succeeded, and the timeline clip types (green zoom, teal speed, gold caption, mauve element).

### Design Principles
1. Readable first: no text below 12px (0.75rem); secondary text keeps at least 5.5:1 contrast on panel surfaces. Type sizes come from the `--text-*` tokens in `src/styles.css`.
2. Good defaults over controls: the automatic result should be exportable without opening a panel; advanced knobs live behind disclosure.
3. Show what the automation did: auto-generated edits are visibly marked and removable in one click.
4. Motion is the product: UI chrome stays quiet so the preview carries the energy.
